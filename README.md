# 나만의 프롬프트 관리 프로그램

GenAI 미션을 수행하며 쌓인 프롬프트(텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화 등)를
한 곳에서 등록·검색·즐겨찾기 관리할 수 있는 **파이썬 콘솔 프로그램**입니다.
외부 라이브러리 없이 파이썬 기본 문법만으로 구현했으며, 기능별로 함수를 분리해 관리했습니다.

## 실행 방법

```bash
# 1. 저장소 클론
git clone https://github.com/{your-id}/prompt-manager.git
cd prompt-manager

# 2. Python 버전 확인 (3.10 이상)
python3 --version

# 3. 프로그램 실행
python3 prompt_manager.py
```

실행하면 아래와 같은 메뉴가 나타나며, 번호를 입력해 원하는 기능을 선택합니다.

```
=== 나만의 프롬프트 관리 ===
1. 프롬프트 추가
2. 프롬프트 목록
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 관리
7. 즐겨찾기 목록
0. 종료
```

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목/내용/카테고리를 입력받아 새 프롬프트를 등록합니다. 빈 값은 재입력을 요청합니다. |
| 2 | 프롬프트 목록 | 등록된 모든 프롬프트를 제목·카테고리·즐겨찾기(⭐) 상태와 함께 출력합니다. |
| 3 | 카테고리별 조회 | 카테고리를 선택하면 해당 카테고리의 프롬프트만 출력합니다. |
| 4 | 프롬프트 검색 | 제목 또는 내용에 포함된 키워드로 검색합니다. |
| 5 | 프롬프트 상세 보기 | 번호를 입력하면 제목/카테고리/즐겨찾기/전체 내용을 출력합니다. |
| 6 | 즐겨찾기 관리 | 번호를 입력해 즐겨찾기를 추가/해제합니다. |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아서 보여줍니다. |

> 프로그램 실행 중에 추가한 프롬프트와 즐겨찾기 상태는 유지되며, 종료 시 초기화됩니다.

## 등록된 프롬프트 카테고리

- **텍스트 생성** : 블로그 글, 이메일, 요약문 등 텍스트 결과물을 위한 프롬프트
- **이미지 생성** : 썸네일, 일러스트 등 이미지 결과물을 위한 프롬프트
- **영상 생성** : 광고 스크립트 등 영상 콘텐츠 관련 프롬프트
- **페르소나** : 특정 역할/캐릭터를 부여하는 프롬프트
- **자동화** : 반복 작업(요약, 분류 등)을 자동화하는 프롬프트
- **기타** : 위 카테고리에 속하지 않는 프롬프트

기본 데이터로 이전 미션에서 작성한 프롬프트 5개(블로그 글 작성 도우미, 제품 썸네일 생성,
IT 컨설턴트 페르소나, 뉴스 요약 프롬프트, 광고 스크립트 작성)가 미리 등록되어 있습니다.

## 코드 구조

기능별로 함수를 분리하여 하나의 함수가 하나의 역할만 하도록 구성했습니다.

```
prompt_manager.py
├── get_default_prompts()   # 기본 프롬프트 데이터
├── 입력 유틸               # input_non_empty, input_category, input_index
├── 화면 출력               # show_menu, print_prompt_line, print_prompt_list
├── 기능별 함수              # add_prompt, show_list, show_category,
│                            search_prompt, show_detail,
│                            toggle_favorite, show_favorites
└── main()                   # 메뉴 반복 실행
```

## 개발 환경

- Python 3.10 이상 (개발 환경: Python 3.12)
- VSCode + Python Extension
- Git / GitHub

## Git 작업 요약

- `git init`으로 로컬 저장소를 시작하고 `git add`, `git commit`, `git push`로 GitHub에 반영했습니다.
- "프롬프트 목록" 기능은 `feature/prompt-list` 브랜치에서 작업한 뒤 `git checkout main` → `git merge`로 병합했습니다.
- 기능 단위로 10개 이상의 커밋을 남겼습니다.
